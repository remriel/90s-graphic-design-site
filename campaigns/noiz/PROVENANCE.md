# Reference and production provenance

Reference: https://github.com/remriel/90s-graphic-design-site

Reference commit: `b6d932e853e0adb549748a71ff7eb9d84ebaab6d`.

Inspected `globals.css`, `page.tsx` and `README.md` through the GitHub connector and local checkout. The ad adopts the repository's exact six-color palette and translates its outlined poster typography, black offset shadows, printed dots, Courier labels, ticker and fake browser treatment into four animated ad layouts. No changes to the website source were required.

Original product asset generated using the built-in image-generation tool. Exact prompt in asset-prompt.txt. Original generated alpha retained; only geometric resize, rotation and compositing are applied during animation. No Python image editing was used to redesign the product.

Audio is synthesized in render.py from oscillators and deterministic noise. No external music, footage, photographs, logos, product specifications or prices were used. NOIZ is a fictional campaign name and the product is a concept render.

Fonts use Windows-installed Impact and Courier New, not packaged in this repository.
